# kernic-site

Marketing and docs site for [kernic](https://github.com/intentionaut/kernic). Built with Astro.

The site is a working example of its own product. Every color, font, radius and gradient comes
from tokens generated by the local `kernic` CLI (`kernic-io` system, neon vibe). There are no
hand-written hex values anywhere.

## How it works

- `"kernic": "file:../kernic"` installs the sibling CLI repo as a dependency.
- `npm run tokens` regenerates `src/styles/tokens.css` with `kernic export kernic-io -f css`.
- The landing page shows real `kernic export` output for css / tailwind / json / design.md.
  `/docs/tokens` renders its whole reference from `tokens.json`.
- `design.md` and `tokens.json` in the root are the agent context files from
  `kernic context kernic-io -o .`.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Regenerate tokens, then start Astro dev server |
| `npm run build` | Regenerate tokens, then static-build to `dist/` |
| `npm run preview` | Serve the production build |

Light mode is the default. The toggle in the header saves your choice in localStorage.

## Changing the look

Don't edit token values by hand. Tune the system instead:

```bash
npx kernic studio kernic-io        # visual editor
# or edit ~/.config/kernic/systems/kernic-io.json
npm run dev                        # tokens regenerate on boot
```
